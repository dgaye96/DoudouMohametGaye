01

Intelligence artificielle / RAG / Gestion des connaissances

COAR
Intelligence Box

Problème

L'analyse des rapports annuels des bureaux pays exige de naviguer dans un vaste ensemble de connaissances structurées et non structurées.

Approche

Une solution de Retrieval-Augmented Generation 100 % locale pour l'ingestion, le découpage, les embeddings, la recherche sémantique et la revue générée par IA.

Technologie

Ollama · Qdrant · FastAPI · React · Python · Vector search

Impact

Interroger les rapports, les comparer aux orientations de l'UNICEF et identifier les écarts sans envoyer les connaissances dans le cloud.
